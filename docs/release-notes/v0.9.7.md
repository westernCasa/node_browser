NODE 0.9.7 fixes two things found in 0.9.6. Thank you for testing.

NODE updates itself on Windows, and on a Mac from 0.9.6 on. Copies of 0.9.5 or earlier on a Mac need this version downloaded by hand once.

## What's fixed

- **Captchas stay in their tab.** Clicking a captcha (the "I'm not a robot" box or a picture puzzle) could switch you back to the tab you had open before. It now stays where you are.
- **The shield counts every block.** The number on the shield next to the address could miss an ad or tracker blocked in the first moment a page loads. It now counts them all.

## Which file to download

Scroll down to **Assets** and download one file:

| Your computer | Download |
| --- | --- |
| Mac with an Apple chip (M1, M2, M3, M4 or later) | `NODE-0.9.7-mac-arm64.dmg` |
| Mac with an Intel processor | `NODE-0.9.7-mac-x64.dmg` |
| Windows | `NODE-0.9.7-win-x64.exe` |
| Linux | `NODE-0.9.7-linux-x86_64.AppImage` |

Not sure which Mac you have? Click the Apple menu in the top-left corner and choose **About This Mac**. If the line "Chip" says Apple M1, M2, M3 or M4, download the Apple chip file. If it says "Processor" with Intel, download the Intel file.

You can ignore the other files, including **Source code (zip)** and **Source code (tar.gz)**. They are for developers.

## Installing on a Mac

If you have 0.9.6, NODE updates itself: when the update is ready it offers to restart. Otherwise:

1. Open the downloaded `.dmg` file.
2. Drag **NODE** into the **Applications** folder, replacing the old one if you have it.
3. Open NODE from Applications.

NODE is signed and checked by Apple, so it opens like any other app. Copies of 0.9.5 or earlier can't update themselves; download this version by hand once.

## Installing on Windows

1. If your browser warns about the download, choose **Keep**.
2. Open the `.exe` file. If you see "Windows protected your PC", click **More info**, then **Run anyway**.
3. Follow the installer.

Windows copies of NODE check for updates and install them by themselves.

## Installing on Linux

Download the `.AppImage` file, make it executable (right-click → Properties → Allow executing, or `chmod +x`), and open it.

## Known limits

- The first time NODE saves a password on a Mac, macOS may ask whether NODE can use its "Safe Storage" key in your keychain. Click **Always Allow**. If you are coming from 0.9.5 or earlier, it asks once more: click **Always Allow** again, or NODE can't read your saved passwords and API keys.
- Signing in to Google accounts opens in a separate Chrome-based window.
- On a Mac, passkeys (Touch ID / iCloud Keychain sign-in) are turned off; sites offer password sign-in instead.

## Reporting a problem

In NODE's menu bar, choose **Help → Report a Problem…**. NODE copies its diagnostics and opens a short bug form on GitHub. Paste them where the form asks, with what you were doing when it went wrong.
