NODE 0.12.0 adds sync and citations. Your trails can now sync between your computers, and soon with NODE on your phone, without an account. And you can export a trail's sources as citations for Zotero or Overleaf. Thank you for testing.

NODE updates itself on Windows, and on a Mac from 0.9.6 on. Copies of 0.9.5 or earlier on a Mac need this version downloaded by hand once.

## What's new

- **Sync your trails between devices.** Open Settings → Sync and choose **Pair a device…**. NODE shows a QR code and a code you can copy. On another computer, choose **Enter a code…** in the same place and paste it. The NODE phone app, coming to the App Store and Google Play, scans the QR code.
  - No account. The pairing code is the only key, and it stays on your devices.
  - Your trails are encrypted on your device before they are sent, so NODE's sync server can't read them. It deletes each change once your other devices have it, after 30 days at most.
  - All trails sync both ways: cards, links, groups, notes, questions and the timeline. When the same thing was changed on two devices, the latest change wins.
  - Changes are sent a moment after you make them, and NODE checks for changes from your other devices every 10 seconds. Settings → Sync shows "Syncing…" while it works, and when it last synced.
  - Deleting a trail deletes it on all your devices. A notice says which device deleted it and offers **Undo**.
  - Settings → Sync lists your paired devices and when each last synced. **Remove** stops a device from syncing. **Stop syncing on this computer** turns sync off here; your trails stay.
  - Saved copies of pages, screenshots and audio don't sync. Neither does where you left the canvas or which trail is open.
- **Export citations.** In the trail switcher, a trail's **…** menu has **Export citations…**. It saves the trail's page cards as BibTeX (.bib) or CSL-JSON (.json), for Zotero, Overleaf and other reference managers. When a page becomes a card, NODE reads the citation details the page carries (authors, date, journal or site, publisher, DOI, volume, issue and pages). Each entry has the address and the day you first visited it. Pages of media moments are included, with the moment's times. Timeline-only visits and sign-in pages are left out. Pages saved before this version have the title, address and date.
- Trail files now carry each page's citation details, so they come back when the file is opened.

## What NODE sends

- **New, only if you turn on sync:** your trails, encrypted on your device, go to NODE's sync server (the same server as share links). The server sees only random ids, never your trails, device names or the pairing code. Without pairing, nothing is sent.
- Everything else is as before, and listed in the README under "What NODE sends".

## Which file to download

Scroll down to **Assets** and download one file:

| Your computer | Download |
| --- | --- |
| Mac with an Apple chip (M1, M2, M3, M4 or later) | `NODE-0.12.0-mac-arm64.dmg` |
| Mac with an Intel processor | `NODE-0.12.0-mac-x64.dmg` |
| Windows | `NODE-0.12.0-win-x64.exe` |
| Linux | `NODE-0.12.0-linux-x86_64.AppImage` |

Not sure which Mac you have? Click the Apple menu in the top-left corner and choose **About This Mac**. If the line "Chip" says Apple M1, M2, M3 or M4, download the Apple chip file. If it says "Processor" with Intel, download the Intel file.

You can ignore the other files, including **Source code (zip)** and **Source code (tar.gz)**. They are for developers.

## Installing on a Mac

If you have 0.9.6 or later, NODE updates itself: when the update is ready it offers to restart. Otherwise:

1. Open the downloaded `.dmg` file.
2. Drag **NODE** into the **Applications** folder, replacing the old one if you have it.
3. Open NODE from Applications.

NODE is signed and checked by Apple, so it opens like any other app.

## Installing on Windows

1. If your browser warns about the download, choose **Keep**.
2. Open the `.exe` file. If you see "Windows protected your PC", click **More info**, then **Run anyway**.
3. Follow the installer.

Windows copies of NODE check for updates and install them by themselves.

## Installing on Linux

Download the `.AppImage` file, make it executable (right-click → Properties → Allow executing, or `chmod +x`), and open it.

## Known limits

- The NODE phone app is not in the App Store or Google Play yet. Until it is, sync works between computers.
- Sync and citations are not in the Chromium build yet.
- When two devices change the suggestions sidebar's pinned keywords at the same time, the later list replaces the other.
- Citation details come from what the page provides. Pages without citation tags export with the title, site, address and date.
- Searching past trails doesn't search the text of saved copies yet.
- Share links (Create Link) still use the older trail format: they carry pages, threads and notes, not the canvas layout. To share the canvas, use **Save File**.
- Trail files from 0.9.x open in the preview as before, with **Open as New Trail** and **Merge**. Merging is not available for the new canvas files yet.
- Screenshots and voice notes are not included when you share a trail.
- On a Mac, passkeys (Touch ID / iCloud Keychain sign-in) are turned off; sites offer password sign-in instead.
- Signing in to Google accounts opens in a separate Chrome-based window.

## Reporting a problem

In NODE's menu bar, choose **Help → Report a Problem…**. NODE copies its diagnostics and opens a short bug form on GitHub. Paste them where the form asks, with what you were doing when it went wrong.
