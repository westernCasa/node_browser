NODE 0.9.6 adds a sidebar layout and is the first version signed by Apple. Thank you for testing.

If you have NODE on Windows, it updates by itself. On a Mac, download this version once and replace the old one in Applications. From now on, Macs update by themselves too.

## What's new

- **Sidebar layout.** Your tabs, tools and trails in one column on the left, so long tab titles stay readable. Turn it on in **Settings → Tabs → Layout**, or **View → Use Sidebar Layout**. The top bar stays the default.
- **Three widths.** Full, a compact rail with icons only, or hidden. Press **⌘S** (Ctrl+S on Windows) to hide or show it, and right-click its empty space to switch between full and compact.
- **Trails in view.** The sidebar shows the trail you're on and lists your other trails. Click one to switch, or start a new trail.
- **CommandBar.** In the sidebar layout, **⌘L** or a click on the address opens one box for everything: switch to an open tab or a trail, search, go to an address, ask about the page, or run the research agent. **⌘T** opens it for a new tab. Keys: ↑↓ to move, ↵ to open, ⇧↵ for a new tab, Tab to ask, ⌘↵ for the agent, ⌥↵ for a new trail.
- **Signed for Mac.** NODE is signed and notarized by Apple. It opens without a security warning and updates itself.
- **Fix: full-screen toolbar.** In full screen, opening the Menu no longer keeps the toolbar on screen. It slides away when you move the pointer down.

## Which file to download

Scroll down to **Assets** and download one file:

| Your computer | Download |
| --- | --- |
| Mac with an Apple chip (M1, M2, M3, M4 or later) | `NODE-0.9.6-mac-arm64.dmg` |
| Mac with an Intel processor | `NODE-0.9.6-mac-x64.dmg` |
| Windows | `NODE-0.9.6-win-x64.exe` |
| Linux | `NODE-0.9.6-linux-x86_64.AppImage` |

Not sure which Mac you have? Click the Apple menu in the top-left corner and choose **About This Mac**. If the line "Chip" says Apple M1, M2, M3 or M4, download the Apple chip file. If it says "Processor" with Intel, download the Intel file.

You can ignore the other files, including **Source code (zip)** and **Source code (tar.gz)**. They are for developers.

## Installing on a Mac

1. Open the downloaded `.dmg` file.
2. Drag **NODE** into the **Applications** folder, replacing the old one if you have it.
3. Open NODE from Applications.

NODE is now signed and checked by Apple, so it opens like any other app. There is no "cannot check" message and no Open Anyway step.

**Updates on a Mac:** from 0.9.6 on, NODE updates itself, as it does on Windows. Copies of 0.9.5 or earlier can't, because they weren't signed, so download 0.9.6 by hand this one time.

## Installing on Windows

1. If your browser warns about the download, choose **Keep**.
2. Open the `.exe` file. If you see "Windows protected your PC", click **More info**, then **Run anyway**.
3. Follow the installer.

Windows copies of NODE check for updates and install them by themselves.

## Installing on Linux

Download the `.AppImage` file, make it executable (right-click → Properties → Allow executing, or `chmod +x`), and open it.

## Known limits

- The first time NODE saves a password on a Mac, macOS may ask whether NODE can use its "Safe Storage" key in your keychain. Click **Always Allow**. After this update it asks once more, because the app is now signed: click **Always Allow** again, or NODE can't read your saved passwords and API keys.
- Signing in to Google accounts opens in a separate Chrome-based window.
- On a Mac, passkeys (Touch ID / iCloud Keychain sign-in) are turned off; sites offer password sign-in instead.

## Reporting a problem

In NODE's menu bar, choose **Help → Report a Problem…**. NODE copies its diagnostics and opens a short bug form on GitHub. Paste them where the form asks, with what you were doing when it went wrong.
