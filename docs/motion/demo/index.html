01 · Sound toggle

Sound: one / all

Border and text fade to violet when it turns on (200ms, ease-enter) and back when it turns off (120ms, ease-exit). The word swaps instantly. The colour follows the state NODE confirms, so the demo waits 40ms like the app does.

02 · Card "read" state

A suggestion you opened

The card dims to 60% (200ms, ease-move) and a "read" badge fades in (200ms, ease-enter). It only goes one way: a card never turns back to unread.

08 · Mosaic tab windows

Tabs move into and out of the grid

Focus → Mosaic: the other tabs wait in their tiles underneath; the active tab shrinks into its tile (320ms, ease-out). Mosaic → Focus: the active tile grows over the others (200ms, ease-out), and they are hidden once covered. Opening or closing a tab in Mosaic moves every tile to its new cell (200ms, ease-in-out); a new tab appears in place.

The real tab windows use Electron's built-in curves: ease-out stands in for --ease-enter and ease-in-out for --ease-move, so this page uses the same CSS keywords.
