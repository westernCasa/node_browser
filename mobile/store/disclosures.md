# Store forms: what to answer

These answers match what the app does as of version 1.0.0. If a feature changes what is sent, update this file, the privacy policy and both store forms together.

## Apple: App Privacy ("nutrition label")

Data used to track you: **No**. Tracking domains: none. No App Tracking Transparency prompt.

Data collected. This is the cautious answer: the services NODE sends data to on your behalf may keep it.

| Data type | Used for | Linked to the user | Used for tracking |
| --- | --- | --- | --- |
| Contact Info → Email Address (Unpaywall, only if Full text is on) | App Functionality | No | No |
| Search History (Wikipedia, Brave, DuckDuckGo) | App Functionality | No | No |
| Browsing History (page addresses sent to AI, only after consent) | App Functionality | No | No |
| User Content → Other User Content (page text and questions sent to AI, only after consent) | App Functionality | No | No |

Everything else: not collected.

## Google Play: Data safety

- Does your app collect or share any of the required user data types? **Yes**
- Is all user data encrypted in transit? **No.** NODE can send to a model server on the person's own network over plain http. Answer Yes only if http model servers are removed.
- Do you provide a way for users to request that their data is deleted? **Yes.** Settings → Your data → Delete all NODE data deletes everything; nothing is kept elsewhere.

| Data type | Collected | Shared | Optional | Purpose |
| --- | --- | --- | --- | --- |
| Personal info → Email address | Yes | Yes (Unpaywall) | Yes | App functionality |
| App activity → In-app search history | Yes | Yes (Wikipedia, Brave, DuckDuckGo) | No | App functionality |
| Web browsing → Web browsing history | Yes | Yes (AI provider the user chose) | Yes | App functionality |
| App activity → Other user-generated content | Yes | Yes (AI provider the user chose) | Yes | App functionality |

The data is processed when the user asks for it. It is not used for analytics, ads, marketing or fraud prevention.

## Account deletion

NODE has no accounts, so Apple 5.1.1(v) and Google's account deletion rule don't apply. The privacy policy says so.

## Age rating

- Apple: answer **Yes** to unrestricted web access. Answer No to everything else, including the social-media questions. Expected rating: **16+**.
- Google (IARC questionnaire): category Productivity or Tools. Users can reach unrestricted internet content: Yes. The app shares content generated by AI: Yes. No user-to-user chat, no purchases, no location sharing.
- Google target audience: 18 and over. Not in the Families program.

## Google Play: other App content answers

- Ads: **No**
- App access: all features are available without an account. The review notes below explain the Demo AI.
- Generative AI: **Yes.** Users can ask questions about a web page. Answers come from the AI provider the user chooses (xAI Grok, their own server) or from on-device Demo. Users can report an answer with ⚑ Report on every answer, which emails the developer from inside the app.
- News app: No. Health: No. Financial features: No. Government app: No.

## Export compliance (Apple)

NODE only uses encryption built into iOS (HTTPS, Keychain). `ITSAppUsesNonExemptEncryption` is set to NO in app.json, so App Store Connect won't ask.
